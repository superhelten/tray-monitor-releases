# Tray Monitor – downloads

Ready-built installers for **Tray Monitor**, a system, service and security monitor that lives in the Windows notification area. The source code is in a private repository; this repository only holds the releases.

## Install

1. Download `Tray-Monitor-Setup-x.y.z.exe` from the [latest release](../../releases/latest).
2. Run the installer. It installs for all users in `C:\Program Files\Tray Monitor` and asks for administrator rights.
3. Windows SmartScreen may show "Unknown publisher" because the installer is not code-signed: choose **More info → Run anyway**.

## Updates

The app checks this repository for new versions at startup and every 6 hours, downloads them in the background and installs when you quit.
